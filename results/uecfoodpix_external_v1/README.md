# UECFoodPixComplete external stress-test outputs

The [fixed protocol](../../UECFOODPIX_EXTERNAL_PROTOCOL.md) predates outcome
inspection. `external_records.jsonl` stores all paired scores and prediction
outcomes; `external_transport.jsonl` supplies BAT and SpatialW1;
`external_summary.json` contains all aggregate analyses and source-cluster
intervals. `uecfoodpix_selected_ids.json` records the filtered official
train/test split, and `uecfoodpix_manifest.json` records image counts and
archive identity. Full prepared arrays and heatmaps are not redistributed.

The original dataset allows non-commercial research use only. Do not put its
raw archive, original images, masks, or the QA contact sheet in a public
repository without checking the creators' terms.
